# PersonaLink MySQL v1.0.1 发布说明

发布日期：2026-09-08  
发布级别：稳定补丁版  
兼容基线：`v1.0.0`  
数据库变更：无

## 修复内容

本版本修复线上照片墙在低带宽或网络抖动时频繁显示“网络错误”的问题。

- 照片墙列表不再一次返回全部 base64 头像，只返回轻量资料和头像地址。
- 新增按用户读取头像的接口；浏览器配合 `loading="lazy"` 在需要显示时加载。
- 班级列表与照片墙并行请求，减少串行等待。
- GET 请求遇到瞬时网络失败时自动重试一次。
- API 超时由 10 秒调整为 30 秒，并区分响应慢、服务器不可达和设备离线。
- Nginx 配置模板与独立配置片段启用文本及 JSON gzip。

## 已部署服务器升级步骤

以下命令一行一条执行。升级不修改 MySQL 表和数据，但仍应先备份：

```bash
sudo /usr/local/sbin/backup-personalink
cd /srv/personalink
git status --short
git fetch --tags origin
git switch --detach v1.0.1
cd /srv/personalink/backend
npm ci --omit=dev
npm run db:verify
cd /srv/personalink/frontend
npm ci
npm run build
sudo install -m 644 /srv/personalink/deploy/personalink-gzip.conf /etc/nginx/conf.d/personalink-gzip.conf
sudo systemctl restart personalink
sudo nginx -t
sudo systemctl reload nginx
sleep 2
curl -fsS http://127.0.0.1:3003/health && echo
curl -fsS http://127.0.0.1:3003/api/version && echo
curl -fsS -o /dev/null -w 'photowall_http=%{http_code} bytes=%{size_download} seconds=%{time_total}' http://127.0.0.1:3003/api/photowall && echo
```

版本接口应包含 `"version":"1.0.1"`，照片墙应返回 HTTP 200，且列表大小应显著低于旧版约 1.54 MB。

## HTTPS 待办

当前外网 443 无法连接，浏览器会显示不安全提示。完成 Ubuntu 教程第 13 节的域名与 Certbot 配置，并确认云安全组及 UFW 允许 TCP 443：

```bash
sudo ufw allow 'Nginx Full'
sudo certbot --nginx -d peaceinside.fun
sudo nginx -t
sudo systemctl reload nginx
curl -I https://peaceinside.fun
```

如果 Certbot 失败，先确认 DNS 的 `43.156.217.98` 确实是当前服务器公网 IP，并检查云厂商安全组已放行 80 和 443。

## 回滚

若升级后需要回到旧代码，先保留故障日志，再执行：

```bash
cd /srv/personalink
git switch --detach v1.0.0
cd backend
npm ci --omit=dev
cd ../frontend
npm ci
npm run build
sudo systemctl restart personalink
```

本版本没有数据库变更，所以代码回滚不需要恢复数据库。不要删除或移动 `v1.0.0`、`v1.0.1` 标签。
