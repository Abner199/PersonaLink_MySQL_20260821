# PersonaLink MySQL v1.0.0 发布说明

发布日期：2026-09-04  
发布级别：首个稳定版  
Git 标签：`v1.0.0`

## 版本定位

`v1.0.0` 是 PersonaLink MySQL 首个固定、可下载、可部署和可恢复的稳定基线。该标签发布后不再移动；以后所有优化从它创建新分支，并使用新的语义化版本号发布。

## 包含的主要能力

- Vue 3 前端与 Express API。
- MySQL 保存班级、账号、资料、兴趣、同义词和用户上传头像。
- 注册、登录、资料维护、班级浏览、照片墙、搜索与同义词管理。
- 管理员维护班级和用户、查看名单、复制姓名、导出 CSV、重置普通用户密码和修改管理员密码。
- Ubuntu 24.04 + Nginx + systemd + HTTPS 部署流程。
- MySQL 自动备份、完整性校验、恢复和跨服务器迁移流程。

## 运行环境

- Ubuntu 24.04 LTS（服务器教程目标环境）
- Node.js 22.x
- npm（使用仓库锁文件和 `npm ci`）
- MySQL 8.0 或更高版本
- Nginx；生产环境推荐配置 HTTPS

## 下载和检出

只下载该稳定版本：

```bash
git clone --branch v1.0.0 --single-branch https://github.com/Abner199/PersonaLink_MySQL_20260821.git
```

已有仓库切换到该版本：

```bash
git fetch origin tag v1.0.0
git switch --detach v1.0.0
```

需要基于该版本继续优化时，不要直接修改标签，先创建分支：

```bash
git switch -c feature/my-improvement v1.0.0
```

也可在 [GitHub Release 页面](https://github.com/Abner199/PersonaLink_MySQL_20260821/releases/tag/v1.0.0) 下载自动生成的 ZIP 或 tar.gz 源码包。

## 部署和迁移

- 新服务器完整部署请阅读[Ubuntu 24.04 部署与零丢数据迁移教程](../Ubuntu24.04从GitHub部署与零丢数据迁移教程.md)。
- 仅安装代码和模拟数据时，检出 `v1.0.0` 后执行教程的建表与第 9.1 节模拟数据导入。
- 迁移真实运行数据时，必须同时保存该 Git 版本和 MySQL 四件套备份，不能只下载源码。
- 本版本未引入独立数据库迁移编号；全新数据库直接运行 `npm run db:schema`。

## 版本识别

- 页面右下角显示 `PersonaLink v1.0.0`，点击可打开本版本 Release。
- `GET /api/version` 返回产品名、版本、发布标签、API 版本和数据库类型。
- `GET /health` 在数据库正常时返回 `status: ok`、`database: mysql` 和 `version: 1.0.0`。
- 仓库根目录 `VERSION`、前后端 `package.json` 均记录 `1.0.0`。

## 验证结果

发布前已通过：前端生产构建、后端 JavaScript 语法检查、MySQL 建表和模拟数据导入、管理员与普通用户核心流程、数据备份、新库恢复及恢复后清单比对。详细证据见[验证报告](../test-report.md)。

## 已知限制与升级建议

- 教学演示密码不适合真实公网业务；接入真实数据前应更换数据库和账号密码。
- 普通用户接口仍需补充完整会话鉴权、速率限制、上传校验和审计日志。
- 依赖安全升级必须在开发环境回归测试，不要在生产服务器直接运行 `npm audit fix --force`。
- 后续兼容修复发布为 `v1.0.1`；新增兼容功能发布为 `v1.1.0`；不兼容变更发布为 `v2.0.0`。
