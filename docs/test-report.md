## 说明

- 验证使用临时端口 `3307`，不会覆盖电脑上可能存在的正式 MySQL。
- CSV 按钮已在浏览器中执行并出现“已导出 30 名学员”；由于自动化浏览器未取得下载事件，建议正式上线前再人工打开一次下载文件，确认 Excel 显示正常。
- npm 依赖审计仍可能报告旧依赖的间接风险。本次没有使用可能造成破坏性升级的 `npm audit fix --force`；如要升级，应另行测试全部功能。
- 2026-09-04 的脚本增强测试使用模拟导出，不改动任何 MySQL；原有 MySQL 8.4 独立测试库的真实导出与新库恢复结果仍作为数据库恢复依据。
- 上线前仍应按 [Ubuntu 部署与迁移教程的验收清单](./Ubuntu24.04从GitHub部署与零丢数据迁移教程.md#14-上线后的完整验收) 使用真实域名、HTTPS、正式数据库账号再验收一次。
