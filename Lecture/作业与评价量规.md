# 作业与评价量规

## 任务

基于 PersonaLink 完成一个小功能，并提交设计卡、代码、测试记录与演示。

## 基础要求（60 分）

| 项目 | 分值 | 达标标准 |
| --- | ---: | --- |
| 项目能启动 | 10 | 前后端都能启动，页面能打开 |
| 页面改动 | 15 | 有明确、可见、符合主题的界面改动 |
| 交互逻辑 | 15 | 至少一个表单/按钮有正确校验或反馈 |
| 代码说明 | 10 | 能说清改了哪些文件及作用 |
| Git 提交 | 10 | 至少一条有意义的提交信息 |

## 进阶要求（30 分）

| 项目 | 分值 | 达标标准 |
| --- | ---: | --- |
| API 或数据联动 | 15 | 正确使用已有 API，或新增简单前后端链路 |
| 测试记录 | 10 | 有成功、失败、边界三类测试 |
| 文档与演示 | 5 | 有功能说明和清楚演示 |

## 挑战加分（10 分）

- 设计合理的新业务规则，并在前后端都处理。
- 处理移动端布局或无障碍焦点状态。
- 使用 Tag 固定一个经过测试的版本。

## 不计分但必须遵守

- 不提交真实个人隐私数据。
- 不把演示级密码或 JSON 文件方案描述为生产安全方案。
- 借鉴代码必须能解释；无法解释的内容不作为个人成果。
