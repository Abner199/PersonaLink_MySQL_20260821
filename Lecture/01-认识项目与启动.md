# 第 01 课：认识项目与启动

## 本课目标

你能在本机启动前端和后端，并能说出为什么要开两个终端。

## 你会看到什么

```text
浏览器：http://localhost:3000  -> 页面
后端：  http://localhost:3003  -> { "message": "Server is running!" }
```

## 跟着做

打开第一个 PowerShell：

```powershell
cd backend
npm ci
npm start
```

看到 `Server is running on http://localhost:3003` 后，不要关闭窗口。

打开第二个 PowerShell：

```powershell
cd frontend
npm ci
npm run dev
```

浏览器打开 `http://localhost:3000`，使用 `admin@system.com / admin123` 登录。

## 你刚才做了什么

- `frontend` 是页面程序，运行在浏览器中。
- `backend` 是接口程序，运行在 Node.js 中。
- 页面需要请求后端来登录、读取班级和保存资料，所以两个服务都要运行。

## 为什么有这么多 npm 命令？

> **重点：`ci` = clean install；`dev` = development。** 这两个缩写与命令命名的历史故事，课堂上请配合 [npm 命令词典与命名故事](./npm命令词典与命名故事.md) 阅读。

先记住：**`npm` 不会自己知道如何启动项目；它会读取当前目录的 `package.json`，执行其中预先写好的脚本。** 因此前端和后端使用的命令不一定相同。

| 命令 | 小白理解 | 本项目什么时候用 |
| --- | --- | --- |
| `npm ci` | 按项目已经锁定好的清单，安装一模一样的工具包 | 第一次运行、换电脑、测试、部署前 |
| `npm install` | 安装依赖；也用于新增或升级一个工具包 | 开发者执行 `npm install axios` 这类新增依赖时 |
| `npm start` | 执行 `package.json` 里的 `start` 脚本 | 本项目后端启动 Express：`node server.js` |
| `npm run dev` | 执行 `package.json` 里的 `dev` 脚本 | 本项目前端启动 Vite 开发服务器 |

`ci` 是 **clean install（干净安装）** 的缩写。它会依据 `package-lock.json` 重建 `node_modules`，不随意升级版本，也不改写锁文件；所以课堂统一环境和部署时优先用它。它可能删除当前目录已有的 `node_modules`，但不会删除你写的 `src` 源码、MySQL 数据或 Git 提交。

本项目不是“前端不能用 `npm start`”，而是前端的 `package.json` 没有定义 `start`，只定义了：

```json
"dev": "vite",
"build": "vite build",
"preview": "vite preview"
```

后端则定义了：

```json
"start": "node server.js",
"dev": "nodemon server.js"
```

因此命令必须和**当前目录**和**脚本名称**对应：在 `backend` 用 `npm start`，在 `frontend` 用 `npm run dev`。可以由开发者自定义脚本名和执行内容，但必须写在 `package.json`，团队需要统一约定，不能临时随便发明一个名称。

想亲自验证时，在 `frontend` 或 `backend` 目录执行：

```powershell
npm run
```

它会列出该目录真实可用的脚本。

## 必做

- [ ] 分别访问 `3000` 与 `3003`，说出两者显示内容的区别。
- [ ] 成功登录管理员账号。
- [ ] 在项目根目录执行 `git status`，截图或记录输出。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| `npm` 找不到 | Node.js 是否安装并重开终端 |
| 页面网络错误 | 后端窗口是否仍在运行、是否为 3003 |
| 端口被占用 | 是否重复启动了服务；先停止旧窗口 |

## 挑战

在浏览器开发者工具的 Network 面板中，找一次登录请求。不要害怕看不懂所有字段，只要找到请求地址中有 `/api/users/login` 即可。
