# PersonaLink 教学包：从 HTML 到前后端小项目

面向只学过少量 HTML 的高职学生。本教学包不假设学生会 Vue、Node.js、Git 或数据库；每课都以“看见效果—动手修改—解释原理—保存成果”为顺序。

## 课程目标

完成课程后，学生能够：

1. 读懂一个 Vue 页面中模板、脚本和样式的大致分工。
2. 修改页面文字、布局、动画和表单校验。
3. 说明浏览器、前端、后端、MySQL 的数据流。
4. 调用一个已有 API，并新增一个小功能。
5. 使用 Git 提交自己的成果，知道 Tag 可以固定版本。

## 使用方法

1. 教师先阅读 [教师备课与授课指南](./教师备课与授课指南.md)。
2. 学生按 `01` 到 `09` 顺序阅读；不要跳过启动和 Git 课。
3. 每次修改前先运行项目，修改后马上刷新确认效果。
4. 每课结束至少完成“必做”，再尝试“挑战”。
5. 不要让学生直接修改生产 MySQL 数据；使用迁移脚本和备份恢复流程操作数据。

## 开课前统一约定

- 本项目使用 MySQL；`backend/db.json` 仅可作为旧版本数据迁移来源，运行时不会读取它。
- 演示账号：`admin@system.com` / `admin123`。
- 所有学生使用自己姓名缩写加学号后四位作为测试邮箱，避免重复注册。
- 未完成作业前不要执行 `git reset --hard`，避免丢失修改。
