# 第 03 课：JavaScript——表单与交互

## 本课目标

理解变量、条件判断和函数如何让页面“会思考”。

## 要打开的文件

`frontend/src/views/Register.vue`

找到 `handleRegister`。它在用户点击注册按钮时运行，先检查密码是否一致、长度是否至少 6 位、是否选择班级，再决定是否调用后端。

## 跟着做

1. 在注册页面故意输入两次不同密码，观察提示。
2. 找到 `if (form.value.password !== form.value.confirmPassword)`，用自己的话写一行注释解释它。
3. 增加一个练习规则：姓名少于 2 个字符时提示“姓名至少 2 个字符”。

示例逻辑：

```js
if (form.value.name.trim().length < 2) {
  errorMessage.value = '姓名至少 2 个字符'
  return
}
```

`return` 的意思是“停止这次注册，不再往下请求后端”。

## 重要边界

前端校验是为了及时提示用户；它不能代替后端校验。当前项目后端也会检查邮箱重复和班级是否存在。

## 挑战

再增加邮箱结尾提示，例如当邮箱不以学校指定后缀结尾时显示友好提醒。只做提醒，不要阻止不同邮箱注册，除非教师明确要求。
